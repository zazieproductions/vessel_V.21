# Glossary

## Domain Terms

| Term | Definition |
|---|---|
| **VESSEL** | The project name. Refers to both the application and the fictional operating system it simulates ("VESSEL OS 0.9.4"). Also one of the 7 hidden rooms (glass skeleton). |
| **VESSEL OS** | The fictional operating system the interface pretends to be. Version 0.9.4, Disc 7 of 7. |
| **Archive** | The central metaphor. A collection of occult/surreal images organized into clusters. The "infinite archive" scrolls indefinitely. |
| **Organism** | The project's self-description: "The organism indexes you as you index it." The archive is alive. |
| **Seed** | An 8-character hex string generated at startup. Drives all procedural generation. Same seed = same experience. |
| **Cluster** | A vertical section of the infinite scroll. Contains 5–14 images, glyphs, diagrams, and warnings. Generated by `generateCluster()`. |
| **Layout** | The spatial arrangement strategy for images within a cluster. 10 options: scatter, spiral, drawer, nave, strip, stack, constellation, cabinet, wound, oriel. |
| **Plate** | An image within a cluster. Borrowed from photographic/museum terminology ("plate 7"). |
| **Treatment** | The visual processing applied to an image: hue rotation, saturation, contrast, blend mode, mask, grain, flip, opacity. |
| **Behavior** | The animation applied to an image: melt, split, reveal, rotate, duplicate, glitch, pulse, invert, burn, orbit. |
| **Anomaly** | A special image placed prominently at regular intervals. 6 types: eye, skeleton, moon, burn, stock, portal. Opens a hidden room on click. |
| **Hidden Room** | A full-screen overlay showing thematic content about a specific concept. 7 rooms: vessel, lunar, eye, room0, burning, micro, nave. |
| **Spawn** | A visual effect created when clicking empty space. 4 types: sigil, text, ripple, swarm. |
| **Glyph** | An SVG sigil overlaid on clusters. 8 variants: concentric circles, triangles, crescents, grids, pentagrams, ellipses, arches, compass roses. |
| **Diagram** | An SVG technical diagram overlaid on clusters. 6 variants: vesica, orbitals, lattice, anatomy map, star chart, circuit seal. |
| **Warning Label** | Styled text label with severity levels: note, caution, forbid. Content from the `WARNINGS` lexicon. |
| **Accession** | A formatted identifier for each cluster (e.g. "ACC-4713.07"), mimicking museum/archive catalog numbers. |
| **Rite** | The boot sequence animation. "Skip rite" button allows bypassing it. |
| **Reticle** | The custom cursor — a crosshair ring with coordinate readout. |
| **Void** | Empty, non-interactive space in the interface. Clicking the void inscribes spawn effects. |
| **Inscribe** | The act of creating a spawn effect by clicking the void. |
| **Seal** | To close an overlay. "seal / esc" button on hidden rooms. |
| **Freeze / Thaw** | Toggle all animations on/off via the `S` key. |
| **Mutate** | Cycle to the next color theme via the `M` key. |
| **Regen** | Regenerate all imagery from a new random seed via the `R` key. |
| **Diagnostic** | Debug overlay showing pointer coordinates, scroll depth, seed, theme, and recent log. Toggle via `D` key. |

## Technical Terms

| Term | Definition |
|---|---|
| **mulberry32** | A 32-bit PRNG algorithm used for all procedural generation. Period of 2³². |
| **RNG** | Random Number Generator. In this codebase, specifically a `() => number` function returning values in `[0, 1)`. |
| **rngFrom** | Factory function that creates a deterministic RNG by mixing a seed with salt values using golden-ratio hashing. |
| **hexSeed** | Function that generates random hex characters using `crypto.getRandomValues`. Used only for initial seed generation. |
| **pointer.ts singleton** | Module-level mutable objects storing pointer position and scroll offset. Bypasses React state for performance. |
| **parallax** | Scroll-dependent vertical offset applied to images via `data-para` attribute and `--para` CSS variable. |
| **data-source-loc** | Compile-time attribute added to JSX elements by the Vite source-tags plugin. Format: `file:line:col`. |
